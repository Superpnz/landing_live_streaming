# Live Streaming Landing / Лендинг для стриминга
Адаптивная вёрстка лендинга по макету Figma с использованием препроцессора SCSS / Responsive landing page built from a Figma mockup using the SCSS preprocessor.
`HTML` `SCSS/SASS` `Figma` `Responsive` `Parcel` | [🌐 Демо / Live Demo](https://superpnz.github.io/landing_live_streaming/)

## 🎨 Design
**Figma mockup:** [View design in Figma](https://www.figma.com/design/QqRjLgoPQ43mdfzHl66Ua3/live-streaming--design-?node-id=1-3&t=BkkohFBzYO6bQTQK-0)

## Ключевые особенности / Key Features
* **Адаптивный дизайн на основе Figma-макета** / Responsive design based on Figma mockup
* **Использование препроцессора SCSS** / Built with SCSS preprocessor for maintainable styles
* **Семантическая HTML-разметка** / Semantic HTML markup
* **Оптимизированные изображения** / Optimized images for fast loading

## Структура проекта / Project Structure
Современный лендинг, построенный с использованием SCSS для стилей и Parcel в качестве сборщика для оптимизации производительности / Modern landing page built with SCSS for styling and Parcel as a bundler for performance optimization.
